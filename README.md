# シャニマス Canvas 高解像度化

ブラウザ版「アイドルマスター シャイニーカラーズ」のCanvas描画を高解像度化するユーザースクリプトです。

ゲーム内の論理座標や画面の表示サイズを維持したまま、PIXI.jsの描画解像度を引き上げます。

## 主な機能

- Canvasの描画倍率を最大4xまで変更
- `Alt + U`で描画倍率を順番に切り替え
- TampermonkeyのメニューからCanvas倍率とFilter解像度を個別に選択
- ウィンドウサイズや画面回転の変化を監視して再適用
- 通常画面だけでなく、Filterを使用する一部画面にも倍率を適用
- 選択した倍率を保存し、次回起動時にも使用

## 対応倍率

`Alt + U`を押すたびに、次の順番で切り替わります。

`自動 → 1x → 1.5x → 2x → 3x → 4x → 自動`

初期設定は`2x`です。

「自動」では、Canvasの表示サイズ、端末のピクセル密度、GPUの描画サイズ上限から倍率を選択します。

## Filter解像度

Tampermonkeyのメニューから、`Canvas倍率に連動`、`1x`、`1.5x`、`2x`、`3x`、`4x`を選択できます。

初期設定は`2x`です。ぼかしなどのFilter処理が重い画面では、Canvasを4xのままFilterだけ1xまたは2xへ下げることでGPU負荷を抑えられます。

## 使い方

1. Tampermonkeyなどのユーザースクリプトマネージャーへ本スクリプトをインストールします。
2. [アイドルマスター シャイニーカラーズ](https://shinycolors.enza.fun/)を開きます。
3. ゲーム画面で`Alt + U`を押すとCanvas描画倍率が切り替わります。Filter解像度はTampermonkeyのメニューから変更します。

現在のCanvas倍率またはFilter解像度は画面左下へ短時間表示されます。Tampermonkeyのメニューから設定を選択した場合は、反映のためページが再読み込みされます。

## 注意事項

- ゲーム内のすべての場所で、アップスケールが正しく処理されるとは限りません。
- 元画像自体の解像度は変わらないため、低解像度の画像素材が高精細になるものではありません。
- 倍率を上げるほどGPU負荷、GPUメモリ使用量、発熱、消費電力が増加します。
- 動作が重い、表示が乱れる、画面が黒くなる場合は、`1x`または`2x`へ下げてください。
- ゲーム側の更新により、動作しなくなる可能性があります。
